# Music Player
Simple ruby music player built for Introduction to Programming unit.

## Installation
Clone or download
Uses Ruby 3.3.7
Run with "ruby music.rb" in the root folder
Display scaling can cause the window to appear extremely small. To fix:
1. Open the properties of the ruby.exe installation file
2. Open the combaitbility tab
3. Click Change high DPI settings
4. Tick "Override high DPI scaling behaviour"

## Controls
- Click an album to select it
- Click a track from the album to play it
- Pause, resume and stop with the buttons in the bottom right.
